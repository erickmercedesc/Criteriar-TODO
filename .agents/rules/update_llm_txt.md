# Actualizar llm.txt tras cambios significativos

**Contexto**: El archivo `public/llm.txt` es la guía principal para LLMs y bots sobre el sistema SecondBrain.
**Regla**: Después de realizar o asistir en cualquier cambio significativo en el funcionamiento general, lógica de negocio, o estructura de la API del proyecto SecondBrain, **DEBES** revisar y actualizar el archivo `public/llm.txt` para asegurarte de que refleje los últimos cambios implementados.
